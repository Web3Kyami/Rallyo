# Contributing to Rallyo

Thanks for your interest in Rallyo.

The project is currently moving quickly toward its first public release. Contribution guidance will expand as the repository stabilizes.

For now:

1. Open an issue before large changes.
2. Keep changes focused.
3. Add or update tests for behavior changes.
4. Never commit secrets, private keys, tokens, or `.env` files.
5. Run the repository's lint/typecheck/test commands before opening a pull request.

By contributing, you agree that your contribution is provided under the project's MIT License.
